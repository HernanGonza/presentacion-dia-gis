# Sistemas de Información Geográfica · presentación Día GIS

Vite + React, 100 % local (sin CDN ni red: fuentes, logos y capturas viven en `src/`).

    npm install        # una sola vez (con internet)
    npm run dev        # http://localhost:5173
    npm run build      # dist/index.html: un único archivo, se abre con doble clic
    npm run guion      # regenera GUION.md

Teclas: ← → mover · N guion del orador · G índice · F pantalla completa.
Contenido: `src/slides.data.js`. Capturas: `src/capturas/` (ver `LEEME.txt`).
